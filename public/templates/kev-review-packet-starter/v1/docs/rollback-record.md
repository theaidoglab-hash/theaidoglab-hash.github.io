# Rollback record

Status: future operating template. This package has no deployed path to roll back.

## Stop using the starter as a public-safe local exercise when

- a fixture is replaced with live, private, customer, asset, or network data;
- a credential, API request, network request, model call, or external integration is added;
- code is given authority to scan, assess, patch, ticket, notify, or decide remediation; or
- the record or receipt no longer has a named owner and an inspectable source boundary.

## Conservative response

Stop the assisted packet path and return to manual review of the authorised source. Preserve only the minimum safe local evidence needed for the reviewer to understand why the path stopped. Do not retry with weaker checks or silently relabel a live input as synthetic.
