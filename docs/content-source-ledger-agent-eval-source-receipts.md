# Source ledger: agent and evaluation learning-source receipts

Status: internal research note for a review-stage public article. Checked 2026-09-25.

## Editorial decision

This is not a ranking, affiliate list, or a republishing project. It compares five official starting points against a named evidence gap. The article's suggested first-week artefacts, decision records, and stop conditions are independently authored AI.DOG exercises; they are not represented as course assignments or provider-endorsed workflows.

Primary lenses: systems trade-offs and reusable decision patterns.

## Sources and limited claims

| Official source | Claim used in the article | Boundary kept in the article |
| --- | --- | --- |
| https://huggingface.co/learn/agents-course/unit0/introduction | The Agents Course describes agent fundamentals, framework material, hands-on work, assignments/challenges, a free certification process, and basic Python/LLM prerequisites. | Completion, a challenge, or a certificate does not prove production permissions, evaluation coverage, business value, or reliability. Do not reproduce course material. |
| https://academy.langchain.com/courses/intro-to-langgraph | The course lists lessons on graphs, routing, agents, state, memory, human feedback/breakpoints, and module feedback. The page currently says free, 55 lessons, about six hours; LangGraph is described as MIT-licensed. | A framework/library licence does not license course text or third-party services. Framework familiarity does not prove a safe workflow or production operations. |
| https://developers.openai.com/api/docs/guides/agents-api/quickstart | The quickstart uses an API key with listed scopes, a hosted sandbox, streamed events, and warns a completed turn does not mean every tool succeeded. | This site never asks readers to add a key or run a provider call. A static/local exercise is not an observed model result, a security approval, or a production run. |
| https://www.promptfoo.dev/docs/getting-started/ | Promptfoo documents a configuration file with prompts, providers, tests and optional assertions; it supports running an evaluation and manually reviewing outputs. Many providers require authentication. | A local evaluation result does not prove live-traffic performance, business impact, privacy review, or trajectory safety. Provider costs and data terms remain separate. |
| https://learn.microsoft.com/en-us/training/paths/evaluate-generative-ai-apps/ | The learning path covers evaluation fundamentals plus running evaluations/generating synthetic datasets, and lists an Azure subscription, portal familiarity, beginner Python, and browser/local development prerequisites. | A free trial is not a no-cost guarantee. Completing cloud-specific exercises does not validate another provider, real data distribution, or organisation approval. |

## Claims intentionally excluded

- Current prices, discounts, availability by country, job placement, certificate market value, completion rate, or quality rankings.
- Any claim that a source is best, sufficient, or will lead to employment.
- Exact library/model/product behaviour beyond the cited pages.
- Any copied lesson, exercise, quiz, answer, source code, or course wording.

## Review triggers

Recheck all source pages before approval/publication and again if this article passes its review date. Remove or revise a receipt when its official link, prerequisite, pricing/access model, licence, or public documentation materially changes.
