學習證據規劃器

用最後留下的證據，選擇學習來源

還沒選來源，可以先做下方一個本機小練習；已有想核對的來源，才比較最多三個。兩條路都不替平台排位或推薦。

僅在本機運作：你填入的來源名稱、URL、核對日期與課節只會暫時留在這一頁的記憶中。規劃器不會儲存、傳送或用來分析，也不會要求個人資料、雇主資料或帳戶。重新整理就會清空；只有你主動複製計畫時，這些資料才會離開頁面。

足夠小而能完成的試跑

不寫 Code：交給人覆核的草稿流程

先開下面的不寫 Code 練習。它提供本機材料；即使沒有 AI 帳戶，也能先練習把草稿交給人覆核。

只在本機做這幾樣

  1. 寫一個虛構使用者、一個仍由人手決定的問題、一種允許輸入、一份草稿輸出，以及一件這次不做的事。
  2. 加兩則練習記錄：一則正常請求，與一則資料缺失、不安全或超出範圍的請求。
  3. 每則先寫預期如何處理：出草稿、交給人或拒絕處理；再記下覆核者的決定與一個原因。

別人可以檢查

一份簡單的輸入／輸出說明、兩個固定情境、預期處理方式，以及看得見的例外路徑。

這份工作也交代了

一位有名字的負責人、最後操作為何留給人手，還有這個練習實際證明什麼與無法證明什麼。

下一步：用提供的六個情境試一次

練習提供合成的供應請求表、手動處理卡、權限核對記錄與覆核記錄。完成這些材料後，才回來勾選上面的檢查。

全程只在本機做：不需要帳戶、不連接其他應用程式、不用真實資料，也不會做外部操作。

還沒叫它作品之前

帶著記錄往前走，不要帶著「成功」宣稱往前走

這次小試跑最多證明你保留了一個有範圍的決策、幾個情境與覆核結果。它不證明商業成效、模型品質、可正式上線，也不代表你有工作經驗。只有能說清楚觀察到什麼時，才把記錄帶到下一步。

這四樣要一起留下

  • 虛構情境要作的決策，以及最後仍由哪一位人員拍板。
  • 允許使用的合成輸入，以及這次明確禁止的外部操作。
  • 六個預期與實際處理方式，包括至少一個交給人或拒絕處理的情境。
  • 覆核記錄，以及為何選擇繼續、修改或停止。

修改，表示記錄應該帶到下一次試跑，不是變成作品宣稱

保留不吻合的地方，做一次更小範圍的重試。日後看得見的修改可以是有用證據；但「已完成」補不回缺少的情境、邊界或決策。
