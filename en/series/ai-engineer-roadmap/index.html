Start learning AI, or grow into an AI Engineer

Choose the route you need now: learn to use AI safely and effectively without writing code, or build from technical foundations through practical work and interview practice.

Choose a learning route

AI foundations

A zero-to-one AI learning route

You do not need to choose a task or project yet, and you do not need to learn to code first. Look around at what AI can help with and where people still decide; when you are ready, start with one small, low-risk task.

  1. 01

    See how AI can help

    Start by looking at drafting, classification, or comparison scenarios. You do not need to pick a task or create an account yet.

    Browse AI work routes →
  2. 02

    Try a first offline exercise when you are ready

    When it feels useful, use fictional data for one manual check so you can see the flow, exceptions, and points that go back to a person.

    Start the no-code exercise →
  3. 03

    Choose a next step when it becomes useful

    Once a direction interests you, name the capability you still cannot show and compare the next learning source.

    Plan the next learning step →

This route lets you explore the basics of using AI safely. It is not AI Engineer training; switch to the AI Engineer route when you want to write code, build, or deploy AI systems.

Use the same three moves at every stop

  1. 01

    Write one decision

    Name who needs which decision and the explicit non-goal before opening a pile of tools.

  2. 02

    Use the primary guide to make the artefact

    Read the first guide in the card and treat “Leave with” as the minimum deliverable; you do not need to read every link at once.

  3. 03

    Check it with one counterexample

    Use the linked question or one fixed acceptance case to test the artefact. Record where it can fail, who reviews it, and the next step.

Do not rush to the next stop before you have an artefact, but do not wait for perfection. Move on with a record once you can explain the decision, trade-off and failure boundary.

How to use this route

This AI.DOG route gives you an order for self-directed learning: each stop names a mechanism, a minimum artefact, and where to return when you get stuck. Teams, levels, and roles ask for different things; this is not an institution’s course, partnership, or hiring promise.
