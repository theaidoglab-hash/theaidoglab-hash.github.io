INTERVIEW LAB

AI Engineer Interview Practice: one question at a time

Fifty-nine practice questions sit in ten capability groups. Each starts with an answer that is only partly right, then helps you fill in the principle, trade-off, failure case, and work that supports what you say.

START FROM A REAL GAP

Do not start with a question number. Start with the evidence you are missing.

Each route has four questions. If you already have a demo, model, or project, choose the route closest to its gap. If you do not have a project yet, start with the no-project route. Leave a small piece of evidence at each step, then use the next question to make the mechanism and likely failure clearer. The point is not to memorise all 59 questions at once.

No project yet: leave your first defensible evidence in four questions

For readers without a demo or portfolio yet. Four fictional, low-risk exercises leave notes you can carry into the next question; no API key, real data, or model is needed.

    Keep after this stepWrite down one fictional, low-risk decision, then name either “do not automate yet” or one simple rule as the baseline and one case that must go to a person.

    Keep after this stepFor the same fictional situation, write three lines: what may enter, what a draft must contain, and which condition must stop and go to a person.

  3. 03 · Boundary people missSecurity, privacy and responsible AI07 / 59 →

    Keep after this stepWrite two fictional uploaded sentences. Mark which is data only and which must never change tool permission or the next action, then name one human handoff.

    Keep after this stepMake a small `source-receipt.md` for one public source: URL, access date, fields you would use, what you cannot verify, and a conclusion you must not make yet.

How to use this map

This AI.DOG practice map is maintained by an anonymous AI practitioner. Each question practises mechanism, trade-off, failure boundaries, and evidence you can show; it is not a company question, a current interview-loop claim, or a hiring prediction.

How to make one question useful

  1. 01

    Choose the capability group closest to your target role and open one question.

  2. 02

    Answer for 90 seconds in your own words. On a second pass, find the principle, trade-off, or stop condition you missed.

  3. 03

    Open a README, test case, or decision record and point to one thing an interviewer could ask about.

Scope note

These AI.DOG exercises are organised around publicly visible recurring topics. Each is for practising mechanism, trade-offs, failure boundaries, and inspectable evidence; none is presented as a company question, company-by-company bank, or current interview process.
