TECHNICAL LLM SYSTEMS

Start with one systems question, not a GPU choice

Want to understand why a model system is slow, runs short of memory, or changes with a long input? Start with the question in front of you. Every guide has a checkable learning boundary; none is hardware-buying advice, a capacity promise, or a benchmark.

For technical learners with basic AI concepts who want to understand how a model system behaves. If you are new to AI, read the glossary first, then return to choose a question.

In plain language: TTFT is the wait from sending a request to seeing its first word; context is the material the model can use this time; and a KV cache temporarily keeps already-read material so it does not need to be recalculated every time.
