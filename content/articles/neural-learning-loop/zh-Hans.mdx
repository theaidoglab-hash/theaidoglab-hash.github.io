模型训练不是“喂数据，等它变聪明”。它不断做四件可检查的事：把 input 变成 prediction、衡量错多少、沿着能减少错误的方向更新参数，然后在未看过的数据再验证。

## 用一个小分类任务看 learning loop

假设要把完全合成的 FAQ case 分成 `supported` 或 `handoff`。**Representation** 是 input 变成 model 可计算特征的方式；**target** 是预先定义的正确 route。model 给出 prediction 后，**loss** 把 prediction 与 target 的差距变成训练信号。

**Gradient** 告诉每个参数：往哪个小方向调整，loss 会下降。**Backpropagation** 是把这个信号由 output 倒传到前面 layers 的计算程序；optimizer 再决定每次改多少。它不保证学到正确因果，只是让当前 training objective 变小。

## 为什么 loss 下降仍未必可用

若 train loss 不断下降，但 validation loss 变差，常见是 **overfitting**：model 记住 training set 的偶然细节，没有学到可延伸的 pattern。也可能是数据重复、target 定义有歧义、split 泄漏未来信息，或 validation case 根本不代表日后决定。

不要先换更大 network。先抽查 input 与 target、确认时间边界、保留简单 baseline、按 failure family 分组看 confusion matrix，再调整 representation、model 或 optimisation。若任务其实只需要 rule 或 human review，这也是有效结论。
