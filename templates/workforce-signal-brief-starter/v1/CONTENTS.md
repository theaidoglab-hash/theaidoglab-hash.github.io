# Package contents

- `README.md`: scope, commands, portfolio walkthrough, and non-claims.
- `workforce-signal-brief-starter.md`: manual worksheet for adapting the exercise.
- `data/`: local source receipt and invented monthly series.
- `src/`: deterministic validation and context-packet construction.
- `tests/`: Node built-in test cases for accepted and rejected routes.
- `scripts/`: deterministic local demo.
- `docs/`: decision, failure, reviewer, and rollback records.
- `expected-output.json`: checked-in output for the successful local demo.

All files are local learning material. No command in this package calls a network service or performs an external action.
